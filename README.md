# Model Concierge 🤵

Локальный «дворецкий» зоопарка диффузионных моделей: сканирует папку `models\`,
по тензорам определяет, **что** за файл перед ним, раскладывает всё по папкам,
собирает правильные команды для `stable-diffusion.cpp` и гоняет их **очередью**
через веб-морду в стиле консоли.

Один файл Python + стандартная библиотека. Без GPU: всё считается на CPU.

---

## 1. Что умеет

- **Сканер и классификатор** — читает заголовки `safetensors`/`GGUF` и по именам
  тензоров определяет роль файла (чекпоинт / DiT / LLM-энкодер / VAE / LoRA /
  motion-модуль / ESRGAN). Имя файла — только подсказка: **тензоры важнее имени**.
- **Лечащая раскладка** — кнопка «Раскидать по папкам» перемещает файлы
  в правильные подпапки и чинит ошибочно разложенное.
- **Конструктор команд** — выпадающие списки: конвейер → модель → режим →
  промпт → лоры (чекбоксы) → «Собрать команду» → «в очередь».
- **Очередь с воркером** — задачи выполняются последовательно, логи пишутся
  в `queue_logs\`, статусы и живой хвост лога — в морде (автообновление 5 с).
  Очередь переживает перезапуск (`queue.json`).
- **Авто-добавки в промпт** — базовое качество + триггеры лор: из ручного
  словаря `TRIGGERS` и **автоматически из метаданных лоры**
  (`activation_word`, `ss_training_comment`, `ss_tag_frequency`).
- **Подсветка совместимости** — SD-лоры помечаются тегами `SD15`/`SDXL`;
  чужая для выбранного конвейера лора — полупрозрачная с красным тегом.
- **«Узнать промпт»** — достаёт промпт из метаданных PNG через
  `sd-cli -M metadata`, а если метаданных нет — просит Qwen2.5-VL (порт 8081)
  описать картинку как промпт.
- **Именование выходов от модели и лор** — `dreamshaper_8+snofs_krea_v1_3D_img.png`:
  разные наборы лор больше не перезаписывают друг друга.

## 2. Быстрый старт

Требования: Python 3.10+, установленный `sd-cpp` рядом (папка `D:\AI_Servers\sd-cpp`).

```bat
cd /d D:\Python\Model_concierge
python model_concierge.py
```

В консоли: `Concierge на http://127.0.0.1:8090, воркер очереди запущен`.
Открыть в браузере: **http://127.0.0.1:8090**

Удобнее — `start.bat`:

```bat
@echo off
cd /d D:\Python\Model_concierge
python model_concierge.py
pause
```

## 4. Конвейеры и аппетиты (CPU, 32 ГБ RAM)

| Конвейер | Состав | RAM | Шаги |
|---|---|---|---|
| SD 1.5 | чекпоинт solo | ~3 ГБ | 20 |
| SDXL | чекпоинт solo | ~8-9 ГБ | 20 |
| QWEN | DiT GGUF + Qwen2.5-VL + VAE | ~15 ГБ | 20 |
| Z-IMAGE | DiT GGUF Q8 + Qwen3-4B + ae | ~11.5 ГБ | 8 |
| KREA2 | всё встроено в чекпоинт | ~13 ГБ | 8 |

Правила: разрешение — главный едок RAM; очередь последовательная, драк за RAM нет;
`upscale` жрёт по размеру **выхода** (x4 от 1366×768 = 5464×3072 — тяжело).

## 5. Классификатор: как он думает

Порядок проверки (важно!):

1. **Это лора?** — ключи `lora_up/lora_down/lora_A/lora_B/lokr` проверяются
   **первыми**. Иначе лоры с именами `*krea*` / `*z_image*` притворяются DiT-ами
   и уезжают в `dit\` (баг v3.15, вылечен в v3.17).
2. Именные правила полных моделей: `z_image/zimage` → DiT/VAE/LLM Z-Image,
   `qwen3` → энкодер Z-Image, `krea` → DiT Krea2, `zit-` → лора Z-Image.
3. Тензоры: `conditioner.embedders` → SDXL; `cond_stage_model` → SD1.5;
   `transformer_blocks+img_in` → Qwen DiT; `model.layers+embed_tokens` → LLM;
   `encoder.down/decoder.up` → VAE; `motion_modules` → AnimateDiff.
4. Имя как последний шанс (`esrgan`, `mmproj`, `vae`…).

Неопознанные файлы в отчёте показывают первые три тензорных ключа — по ним
роль читается за секунду.

### Семья SD-лоры (SD15 vs SDXL)
`label_emb` в тензорах → SDXL; `input_blocks.10/11` → SD1.5; затем метаданные
`ss_base_model_version` и подсказки имени (`_xl`, `pony`, `illustrious`…).

## 6. Авто-добавки в промпт

При включённой галке «авто-добавки» консьерж дописывает в `-p`:

1. Базовое качество конвейера (`EXTRAS`): `sharp focus, highly detailed, …`
2. Триггеры отмеченных лор — приоритет: ручной `TRIGGERS` → метаданные файла.
   Из метаданных вытаскиваются `activation_word`, `ss_training_comment`
   и топ-теги `ss_tag_frequency` (мусор `None/null/1girl/…` отфильтрован).

Блок «АВТО-ДОБАВЛЕНО В ПРОМПТ» под командой показывает, что и откуда уехало
(`[словарь]` / `[метаданные]`). Найденные триггеры видны зелёными `[...]`
прямо у чекбоксов лор.

## 7. Имена файлов и цепочки

Выход именуется как `<модель>[+лора1[+лора2]]_<режим>.<расш>`:

```
majicmixRealistic_v7_img.png
majicmixRealistic_v7+snofs_krea_v1_3D_img.png
realisticVision_lora_i2v.webm
dreamshaper_8_hires.png
```

`картинка→видео` и `upscale` берут на вход файл, вычисленный по той же формуле, —
поэтому **в img2vid отмечай тот же набор лор, что и в задаче-картинке**
(или нигде не отмечай), иначе входной файл не найдётся.

## 8. API (для любознательных)

| Эндпоинт | Метод | Что делает |
|---|---|---|
| `/api/scan` | POST | скан + отчёт + опции конструктора |
| `/api/organize` | POST | раскидать файлы по папкам |
| `/api/build` | POST | собрать команду конструктора |
| `/api/queue` | POST | список задач |
| `/api/queue/add` / `stop` / `clear` / `remove` / `log` | POST | управление очередью |
| `/api/prompt` | POST | «Узнать промпт» (metadata → VL) |
| `/api/explain` | POST | локальный Qwen объясняет отчёт |

> Исторический грабель: `showQueue` когда-то слал GET и получал HTML вместо
> JSON (`Unexpected token '<'`). Все запросы морды — только POST.

## 9. Типовые ошибки в логах и их смысл

| Строка в логе | Диагноз | Лечение |
|---|---|---|
| `get sd version from file failed: ''` | в `--diffusion-model` подсунута **лора** | «Раскидать по папкам», пересобрать команду |
| `VAE tensor … wrong shape (got 512, expected 384)` | чужой VAE для Krea2 | Krea2 собирается **без** `--vae` и `--llm` (всё встроено) |
| `load image from '…_img.png' failed` | img2vid: вход не создан (рассинхрон лор) | одинаковый набор лор в картинке и видео |
| `can not found lora X` | лора чужой архитектуры в `-p` | смотреть подсветку совместимости |
| `model metadata validation failed` | несовместимая пара модель+VAE | проверить роли в отчёте скана |

## 11. Философия проекта

- **Тензоры важнее имени** — имя врёт, заголовок safetensors — нет.
- **Очередь последовательна** — на CPU параллельность только вредит.
- **Меньше байт — быстрее** — на CPU кванты дают скорость (меньше перекачки),
  поэтому GGUF Q8_0 предпочтительнее bf16.
- **Консьерж помнит за тебя** — триггеры, роли, пути и ссылки он держит в голове,
  человеку остаётся творческая часть: промпт и выбор моделей.
